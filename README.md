# Стенд: three.js vs react-three-fiber

Воспроизводимое сравнение производительности императивного `three.js` и
декларативного `react-three-fiber` (R3F) на одинаковых сценах: сколько стоит
R3F и какие способы писать на нём дешёвые, а какие дорогие.

- что и зачем измеряется — `../nir3-spec.md`;
- формат данных — [`docs/DATA.md`](docs/DATA.md);
- как снимать данные (пилот, кампания) — [`docs/MEASURE.md`](docs/MEASURE.md).

## Принципы

1. **Одна спецификация сцены** (`packages/scene-spec`) — контент и параметры
   рендерера. Реализации различаются только способом управления сценой.
2. **Одинаковые точки замера**: `beginFrame → update → beginRender → render →
   endRender` в обеих реализациях; коллекторы общие (`packages/metrics`).
3. **Проверка паритета перед каждой серией**: снимки сцены всех вариантов
   сравниваются с three.js вплоть до побитового равенства кадра.
4. **Только сырые замеры**: harness записывает каждый кадр, клик и отметку
   времени в CSV; метрики считает анализ.
5. **Условия эксперимента контролируются**: production-сборка, cross-origin
   isolation (таймер 5 мкс), случайный порядок прогонов, паузы, версии
   браузеров зафиксированы. Нарушение условий останавливает серию.

## Сценарии

| ID | Что измеряем | Варианты |
|----|--------------|----------|
| S1 | нагрузка на GPU: точки A (заливка), B (вершины), C (вызовы отрисовки) | threejs, r3f-ref |
| S2 | нагрузка на CPU: 3000 анимированных кубиков | threejs, r3f-ref, r3f-ref-central, r3f-state, r3f-parent-state |
| S3 | холодный старт, 100 статичных торов; размер сборки | threejs, r3f |
| S4 | отклик на клик, 2000 кубиков | threejs, r3f-ref, r3f-events |
| S5 | масштабируемость: число объектов 100…51 200 (шаг ×√2) | threejs, r3f-ref |

Браузеры: Chromium 153 и Firefox 155 — все сценарии; WebKit 26.6 — S2–S4
(дополнительная серия: в нём не снимается vsync и нет времени GPU).

## Запуск

```bash
npm install
npm run browsers                     # сборки браузеров пула
npm run typecheck
npm run bench:parity -- s2           # только проверка паритета
npm run bench -- --scenario s2 --browser firefox --repeats 3 --allow-dirty   # отладка
npm run campaign -- list --session r3                                       # план кампании
```

Результаты: `results/<устройство>/<браузер>/<сценарий>/<серия>/` —
`manifest.json` и `runs/*.csv` (см. `docs/DATA.md`).

Ручной просмотр: `npm run dev:r3f` → `http://localhost:5174/?scenario=s4&mode=events`.
